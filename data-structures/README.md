# Data Structures

Implementation of fundamental data structures with examples and explanations.

## 📋 Contents

### Linear Data Structures
- **Array** - Fixed-size sequential collection
- **Linked List** - Dynamic linear data structure
- **Stack** - LIFO (Last In First Out) structure
- **Queue** - FIFO (First In First Out) structure

### Non-Linear Data Structures
- **Binary Tree** - Hierarchical tree structure
- **Binary Search Tree** - Ordered binary tree
- **Heap** - Complete binary tree with heap property
- **Graph** - Collection of vertices and edges

### Hash-based Structures
- **Hash Table** - Key-value pairs with hash function
- **Hash Set** - Unordered collection of unique elements

## 🎯 Learning Objectives

- Learn when to use each data structure
